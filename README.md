# digital-future.ai

Official Android application hub for the three platforms:

- SAKAN
- NEXORA
- HELP-ME

This is a dedicated application project. The approved visual identity uses the real production logos of each platform.

## Release direction

- Android / Google Play first
- Apple/iOS deferred
- One application containing the three platforms
- QR entry point for each platform
- Android App Links / deep links
- Shared language and account experience where appropriate

The four web properties are being audited and stabilized before production app integration.
