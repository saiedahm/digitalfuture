# Official platform logo assets

Upload the four official logo image files into this folder using these exact lowercase filenames:

- `digital-future.png` — Digital Future (parent platform)
- `sakan-europe.png` — SAKAN Europe
- `nexora.png` — NEXORA
- `helpme.png` — Helpme official gold circular logo

Recommended: transparent PNG or square PNG, at least 1024 × 1024 px. Keep each logo centered with clear padding. Do not upload QR codes as logos. The app uses these exact paths and will display the real images after upload.
